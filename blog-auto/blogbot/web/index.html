확인할 것

    최근 기록

    글 목록

    이 프로그램이 쓴 글이에요. 목록에서 지워도 블로그 글은 그대로예요.

    종류제목상태발행

    쇼핑커넥트

    링크 발급만 직접 하시면, 나머지(글쓰기·사진·공정위 문구·예약)는 자동이에요.

    오늘의 쇼핑 키워드

    1키워드 수집매일 자동
    2여기서 확인골라 쓰기 좋은 6개
    3[링크 발행하기]쇼핑커넥트에서 직접 발급
    4링크 넣고 [글쓰기]빈 시간에 예약
    전체 키워드 보기
    분야 고르기

    링크 대기열쇼핑커넥트 열기 ↗

    넣은 링크와 쓴 결과예요. 쓴 링크는 '사용 완료'와 어느 글에 썼는지가 남아요.

    키워드 없이 링크 직접 넣기

    추천 상품

    키워드로 찾은 상품 중 수수료 높고 리뷰 많은 것이에요 (참고용, 읽기만 해요).

    추천 기준 · 직접 키워드로 찾기

    설정

    한 번 넣어두면 돼요. 내 컴퓨터(홈 › BlogAuto)에만 저장돼요.

    기본 설정

    예전 프로그램 폴더가 있어요. API 키·블로그 아이디·로그인을 가져올 수 있어요.

    블로그 계정 최대 3개

    자동 작성과 [시작]은 1번 → 2번 → 3번 순서로 돌아요. 계정마다 로그인·블로그·쇼핑 링크가 따로예요.

    말투 메모 자동 학습

    공개된 글을 6시간마다 확인해서, 직접 고치신 부분을 보고 말투를 배워요. 다음 글부터 반영되고, 직접 고쳐도 돼요.

    문제 해결

    쇼핑커넥트 화면이 바뀌어 추천이 안 될 때, 로봇이 화면을 열어 검색까지만 하고 저장해요. 생긴 zip을 Claude에게 보내주세요.

    작업 기록

    무슨 일을 했는지 시간순으로 남아요. 오류가 나면 이 내용을 Claude에게 보여주세요.
