# 📘 블로그 자동화 (파이썬 앱) — 사용 가이드

> 2026-10-05 v1.1.0. 터미널 없이 더블클릭으로 켜는 맥 앱.
> 예전 Node 버전(`npm run dev`)을 대신해요. 예전 가이드는 `claude/user-guide.md`.

## 1. 설치 (처음 한 번)
1. `블로그자동화-파이썬-v1.0.0.zip` 더블클릭 → 생긴 폴더 안의 **블로그자동화** 앱을 "응용 프로그램" 폴더로 끌어다 놓기
2. 예전 프로그램이 켜져 있으면 끄기 (둘 다 켜두면 글이 두 번 써질 수 있음)
3. 앱 더블클릭
   - "확인되지 않은 개발자" 경고 → **시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 "그래도 열기"** → 다시 더블클릭
   - "파이썬이 필요해요" → [설치 페이지 열기] → Download Python → 설치 → 앱 다시 열기
   - "처음 준비" → [시작] → 3~5분 → "설치 완료" 알림 → 대시보드가 브라우저로 열림
4. 다운로드 폴더에 `naver-bc-automation-main`이 있으면 API 키·블로그 아이디·로그인·예약된 글·대기 링크를 **자동으로 가져옴**

## 2. 매일 쓰기
- 앱을 켜두기만 하면 됨. 대시보드: http://127.0.0.1:8765 (앱을 다시 눌러도 열림)
- **자동 작성** 스위치 켜기 → 10분마다 확인, 예약이 (하루 N편 × 며칠치)보다 적으면 1편씩 써서 네이버 예약
- 비율: **정보글 3편마다 쇼핑글 1편** — 쇼핑글은 "링크 대기열"의 링크로 씀 (없으면 정보글 계속)
- 링크 대기열: 쇼핑커넥트 링크를 줄마다 붙여넣기. 메모(직접 써본 느낌)를 쓰면 후기형, 비우면 정보·추천형
- 글 쓰는 동안 로봇 크롬 창이 뜸 → **닫지 않기**
- 맥이 잠들지 않게 앱이 알아서 막아줌 (덮개는 열어두기)
- 끄기: 대시보드 오른쪽 위 [종료]
- 오류로 꺼지면 10초 뒤 저절로 다시 켜짐

## 3. 발행 방식 (v1.1.0)
- 자동 작성 카드의 **발행 방식**: ⏰ 예약 발행(미리 써서 네이버 예약, 맥이 꺼져도 공개됨) / 🚀 즉시 발행(시간대가 오면 그때 써서 바로 공개, 맥이 켜져 있어야 함)
- '지금 1편 쓰기'에서도 글마다 "빈 예약 칸에 예약 / 지금 바로 발행" 선택
- 글 목록: 성공은 **완료**, 옆에 "예약글 · 날짜" 또는 "즉시 발행 · 날짜". 오류면 ❌ 이유가 적힘. 실제로는 올라갔는데 실패로 보이면 **[완료로 표시]**

## 4. 말투 자동 학습
- 예약된 글을 폰에서 고쳐두면, 공개 6시간 뒤 앱이 블로그를 읽어 AI 초안과 비교 → 고친 습관을 **말투 메모**(설정 카드 아래)에 정리 → 다음 글부터 반영
- 예시 글을 따로 가져올 필요 없음. 메모는 직접 고쳐도 됨, [지금 확인하기]로 바로 비교

## 5. 예약 시간
- 하루 3칸: 오전 9~11시 · 오후 13~16시 · 저녁 19~22시 중 빈 칸, 10분 단위, 지금부터 최소 1시간 뒤
- 하루 몇 편(1~3)·며칠치(1~7)는 대시보드에서 조절

## 6. 문제가 생기면
| 증상 | 할 일 |
|---|---|
| 자동이 꺼지고 "연속 3번 실패" | 대부분 로그인 풀림 → [네이버 로그인 창 열기] → 로그인 → 다시 켜기 |
| "네이버 로그인이 풀려서 자동이 꺼졌어요" | 위와 같음 |
| 스위치가 안 켜짐 | 알림에 적힌 것(API 키/로그인) 먼저 |
| 실패 기록이 쌓임 | [실패 기록 지우기] |
| 설치 실패 창 | [기록 보기] 내용을 Claude에게 (홈 > BlogAuto > logs > setup.log) |
| 그 밖의 오류 | 홈 > BlogAuto > logs 의 오늘 날짜 파일을 Claude에게 |

## 7. 내 데이터
- 홈 폴더 > **BlogAuto**: settings.env(설정), data/blog.db(글·링크), data/naver-session.json(로그인), logs/(기록)
- 앱을 새 버전으로 바꿔도 그대로 유지
